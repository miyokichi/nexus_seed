# Goal Evaluation

## Purpose

Decide whether a Goal's success criteria are met by the current World State and
the results of completed Work.

## Instructions

1. Take each success criterion in turn.
2. Look for the specific World State value or Work result that settles it.
3. Mark the criterion met, unmet, or undecidable from available evidence.
4. Return `satisfied` only when every criterion is met; `not_satisfied` when at
   least one is demonstrably unmet; `unknown` when the evidence does not
   settle it.
5. Cite the evidence for the verdict, and list the criteria still unmet.

## Boundaries

- `unknown` is a legitimate answer. Do not resolve missing evidence by
  assuming success or failure.
- Do not propose new Work, close the Goal, or change any status — the verdict
  is an input to NEXUS SEED's decision, not the decision.
