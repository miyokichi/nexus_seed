# Work Assignment

## Purpose

Decide what a Work item actually *needs* to be done — in terms of capabilities,
not executors.

## Instructions

1. Read the Work item's objective, inputs and completion criteria.
2. Match it against the capability inventory by what each capability
   accomplishes, not by name similarity.
3. State the required capabilities, and separately state any that nothing in
   the inventory currently provides.
4. Justify the match in one sentence per assignment.

## Boundaries

- Never name a provider, endpoint, URL, model or agent. Which executor runs a
  capability is decided deterministically by NEXUS SEED's ProviderSelector,
  and human constraints on providers outrank any advice given here.
- A missing capability is a fact to report, not a problem to work around by
  substituting a loosely related one.
