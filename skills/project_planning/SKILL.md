# Project Planning

## Purpose

A Project is one Goal plus the Work that would achieve it. Given a Goal and the
current World State, propose how that Goal could be pursued.

## Instructions

1. Restate the Goal's objective in terms of an observable end condition.
2. Read the World State for what is already true, so the plan starts from
   reality rather than from zero.
3. Propose one candidate approach; add a second only when there is a real
   trade-off worth a human decision.
4. State success criteria that can be checked against World State later.
5. Name the risks and unknowns that would change the plan if resolved.

## Boundaries

- You return candidates. Creating, persisting or advancing a Project is
  NEXUS SEED's decision, not yours.
- Do not name execution providers, endpoints, models or tools.
- Do not invent a deadline, budget or authority that the Goal does not carry.
