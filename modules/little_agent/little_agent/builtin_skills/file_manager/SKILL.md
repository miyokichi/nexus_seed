# file_manager

## Description
ファイルの探索、読み取り、検索、簡単な作成や更新を支援する。

## When to use
- ユーザーがファイルやディレクトリの確認を依頼したとき
- テキストファイルを読み書きしたいとき
- プロジェクト内の文字列を探したいとき

## Allowed tools
- list_dir
- read_file
- write_file
- search_files

## Instructions
- まず対象パスがワークスペース内にあることを確認する。
- 既存ファイルの上書きは慎重に扱う。
- 大きな変更の前には、どのファイルを変更するかを明確にする。
